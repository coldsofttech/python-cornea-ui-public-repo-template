# example-ui

Native Windows window of the example project, built with [Cornea Shell](https://github.com/coldsofttech/CorneaShell). It serves the web frontend and the HTTP API from inside the window. It is not published to PyPI: the Windows setup carries it.

```sh
uv run --package example-ui example-ui
```

Rename it to your project's name. See the [window guide](docs/guides/ui.md).
