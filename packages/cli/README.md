# example-cli

Command line of the example project, built on [Typer](https://typer.tiangolo.com/) and [Rich](https://rich.readthedocs.io/). It only parses input and shows output; the logic is in `example-package`.

```sh
uvx --from example-cli example-cli --help
```

Rename it to your project's name. See the [command line guide](docs/guides/cli.md).
